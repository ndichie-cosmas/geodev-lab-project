## The Data I need
- LGA Boundaries - GRID3 - https://data.grid3.org/datasets/GRID3::grid3-nga-operational-lga-boundaries/about - Shapefile, ~ 2.62 MB
- Settlement extents — GRID3 — //data.grid3.org/datasets/GRID3::grid3-nga-settlement-extents-v4-1/about — GeoPackage, ~1.88 GB
- Watercourse - Watercourses — OpenStreetMap (via QuickOSM plugin, QGIS) — extracted for Nsukka L.G.A., Enugu State, Nigeria
- Elevation — Copernicus DEM (30 m) — https://portal.opentopography.org - Geotiff - 21.4 MB
